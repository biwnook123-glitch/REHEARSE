# Roadmap

## v0.1 — Local-first alpha

- [x] Multi-format local parsing
- [x] Human-confirmed event model
- [x] Evidence-linked event map and risks
- [x] Dynamic pressure injects and spoken handoffs
- [x] Decision log, local persistence and Markdown/JSON export
- [x] Public project schema and automated tests

## v0.2 — Real-material beta

- [ ] De-identified evaluation corpus with published results
- [ ] Better merged-cell, multi-sheet and malformed-date handling
- [ ] OCR adapter for scanned PDFs
- [ ] Editable moments and dependencies beyond title/time
- [ ] Print-ready PDF rehearsal report
- [ ] Facilitator view with timer, notes and inject sequencing

## v0.3 — Team rehearsal

- [ ] Shared project backend and role-based access
- [ ] Review comments and decision history
- [ ] Rerun sessions and before/after comparison
- [ ] Optional private model adapter
- [ ] Feishu, Slack and task-system output adapters

## v1.0 — Open rehearsal engine

- [ ] Versioned adapter SDK
- [ ] Domain risk-rule packages
- [ ] CLI and API
- [ ] English and Chinese interface
- [ ] Stable migration policy for project files

Roadmap order follows evidence: real-material reliability comes before collaboration breadth.
