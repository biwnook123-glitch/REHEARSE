# Changelog

All notable changes to this project will be documented here.

## [Unreleased]

### Added

- A versioned fixture benchmark with exact extraction, source-reference, risk-recall, traceability and simulation-coverage metrics for seven activity structures.
- A public-preview release checklist, generated-release-note configuration and Dependabot coverage for npm, Docker and GitHub Actions.
- Dynamic material request plans that name the providing role, accepted evidence, purpose and fallback input for the current event.
- Script-to-rundown timing checks with imported script matching, text estimates, human rehearsal timers, downstream impact and traceable timing risks.
- An explicit general-AI comparison boundary and reproducible acceptance cases.
- Seven public-source event structures covering launches, beauty experiences, conventions, multi-city activations, markets and training.
- Risk families for compliance copy, inventory, crowd movement, signal paths and verified contingencies.
- Parallel-track regression tests and public validation notes.

### Changed

- Pinned CI actions to full commit SHAs and made fixture evaluation, dependency audit, tests, production build and Docker build part of the release path.
- Upgraded Ajv to 8.20.0 to clear the published moderate-severity ReDoS advisory affecting the earlier lockfile, and refreshed React/Vite to their current stable release line after migration checks.
- Distinguished start delays, duration extensions and interruption recovery time in the simulator, so duration conflicts no longer invent a late start.
- Quarantined implausibly short timing measurements until a user confirms the recording represents the complete run.
- Ranked simulation scenarios by operational priority and made saved plans easier to discover from the result summary.
- Reduced material-review load by separating people references from flow-blocking conflicts and allowing adopted source values to be revised.
- Added pending/completed validation filters, risk-specific evidence prompts and clearer accessible control states.
- Refocused the product on one job: turning unresolved pre-show dependencies into rehearsed decisions, spoken commands and verified reruns.
- Reduced primary navigation from seven feature pages to four operator steps; dependency maps and voice checks now sit inside the core flow.
- Removed the user-facing readiness score and replaced it with concrete counts for pending decisions, recorded commands and completed reruns.
- Rebuilt voice rehearsal from the selected risk and recorded decision instead of using a generic first-two-moments script.
- Replaced quiz-like rehearsal options with operational drafting prompts.
- Reworked the evidence screen to show actual rule hits and explicit human-review boundaries.
- Tightened interface copy to remove rhetorical headings and decorative English labels.

## [0.1.0] - 2026-09-02

### Added

- Local parsing for spreadsheet, document, PDF, JSON and text materials.
- Human-confirmed dynamic event model and evidence-linked dependency map.
- Material-driven risk rules, pressure injects and spoken handoff comparison.
- Real command rehearsal with decision owner, notification scope and rerun action.
- Leadership-facing rehearsal brief and readiness model.
- Multi-project local persistence plus Markdown and `.rehearse.json` export.
- Public project schema, Docker packaging, CI and contributor documentation.

### Changed

- Replaced quiz-like rehearsal choices with editable operational instructions.
- Capped readiness while blocking risks remain open.
