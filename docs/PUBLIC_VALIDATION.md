# 公开案例验证基线

REHEARSE 的内置样本不是活动模板，也不复刻任何一家公司的完整流程。它们只把公开材料中反复出现的运营结构转写成合成测试数据，用来验证：材料不同，活动模型、风险和压力场景也必须不同。

## 当前规则族

- 参与角色：作为活动模型元数据，检查同一角色是否被多个环节同时占用；不在产品内重新派工或追责。
- 时间与并行：缺失时长、同场地或同资源重叠；不同会场且资源独立的并行不报冲突。
- 设备与备援：影片、演示、直播、签到等主路径是否有已验证备用方案。
- 内容与口径：产品、健康、营养、科研等对外内容是否有审核状态。
- 样品与库存：试用装、礼包、礼品和体验物料是否有数量及补货责任。
- 观众与动线：签到、入场、巡游、合影和离场是否有分流或异常处置。

## 证据边界

这些公开页面证明相应活动结构真实存在，但不能证明 REHEARSE 对任意企业材料都能准确识别，也不能代替安全、合规或现场专业判断。公开预览版发布后，新的文档结构应继续记录操作员复核、误报／漏报和修正时长；无法公开原文件时，只需提交可复现的最小结构或问题描述。
